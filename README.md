# 🐾 Animal Combat (Mokepon Evolution)

Juego táctico y de exploración en tiempo real basado en combates de animales con afinidades elementales (Fuego 🔥, Agua 💧, Tierra 🌱).

## 🛠️ Tecnologías
- **Frontend**: HTML5, CSS3 Moderno, JavaScript ES6+ (Canvas 2D API, WebSockets).
- **Backend**: Node.js, Express, WebSockets (`ws` / `socket.io`).
- **Seguridad**: Autenticación criptográfica de sesiones, validación de esquemas y rate limiting.

---

## 🚀 Inicio Rápido

```bash
# Instalar dependencias
npm install

# Iniciar servidor
node index.js
```

Abre tu navegador en `http://localhost:8080` para jugar.
